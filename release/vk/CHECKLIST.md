# Выкладка «Новогоднего стола: рецепты» в ВК и ОК — чек-лист

Пошаговая инструкция для директора студии — `docs/HANDOFF.md`. Порядок и подводные камни —
`game-studio/docs/PUBLISH.md`, раздел 2. Только ВК и ОК, Playgama не трогаем, язык только русский.
Кабинет — **dev.vk.ru** (не .com). Если не открывается — VPN Happ, профиль «ВК напрямую».

## Что лежит рядом
- `texts.md` — название, слоган, краткое и полное описание, категория, 0+, ключевые слова.
- `icons/icon-576.png` (+278, 150, 75), `favicon-32.png`, `snippet-1120x630.png`.
- `screens/1…8-*.png` — 600×1200, книжные, сняты с живой ссылки без баннера-заглушки.
- `build.zip` (в git не хранится, собрать командой ниже) — сборка для хостинга ВК (index.html в корне архива; без tools, docs, release, .claude).
  Пересобрать: `python3 -I tools/build-zip.py`. Папка для утилиты деплоя: `python3 -I tools/build-zip.py --dir build`.
- `vk-hosting-config.example.json` — образец настройки утилиты деплоя (подставить ID приложения).
- Исходники: `tools/release-art.py`, `tools/release-shots.js`, `tools/build-zip.py`.

## Хостинг: рекомендация
**Основной — хостинг ВК** (бесплатный статический, `@vkontakte/vk-miniapps-deploy`): приложение
отдаётся с серверов ВК, а не с github.io, который в России открывается нестабильно, — модерация
и игроки не зависят от внешнего сайта. GitHub Pages остаётся тестовой ссылкой Романа, не адресом для ВК.
Лимиты хостинга ВК: ZIP до 300 МБ (у нас 42 МБ), без аудио и видео (у нас их нет), 24 загрузки в сутки на приложение,
хранятся 10 боевых версий. Запасной вариант — адрес GitHub Pages в «Размещении» (если деплой на хостинг ВК не получился).

## Что сделает Костя / директор (через браузер на Маке и коннекторы)
1. Создать приложение в `dev.vk.ru/ru/admin/create-app`, тип «Мини-приложение» (если нет — «Игра»), название из `texts.md`. ⛔ SMS — Роман. Записать ID.
2. «Информация»: описание, краткое описание, слоган, Company Name — из `texts.md`.
3. Вписать в `js/config.js`: `APP_URL.vk = "https://vk.com/app<ID>"`, `SUPPORT.vk` (уже стоит: сообщество студии vk.com/club243202759), `SUPPORT.ok` (уже стоит: группа студии ok.ru/group/70000061487179), поднять `version` до 1.0.1; пересобрать `build.zip`; push в `main` (и `gh-pages`).
4. Залить сборку на хостинг ВК (вариант А в `docs/HANDOFF.md`); адреса «Размещения» прописываются сами или вручную; состояние «Включено». Проверить `vk.com/app<ID>`.
5. «Отображение»: Книжная, кнопки «Над окном», адаптация под iPhone «Отключена».
6. «Оформление»: иконка 576 (278 и 150 подставятся), фавикон 32, сниппет 1120×630, скриншоты (переключить «Книжная», 600×1200, по одному, после каждого перезагрузить страницу; минимум 3, загружаем 3–6).
7. «Правовые документы»: «Использовать типовые документы».
8. Проверить внутри ВК (компьютер, iPhone, Android): запуск, рецепты, меню, покупки, план за рекламу, открытка, «поделиться»; вкладка «Сеть» — запросы к api.playgama.com; высота настоящего баннера в альбоме.
9. «Другие площадки» → ОК «Опубликовать» (⛔ Роман). Получить ID ОК → `APP_URL.ok = "https://ok.ru/game/<ID ОК>"`, снова пересобрать, залить, `version` 1.0.2.
10. «Модерация»: всё зелёное → одна заявка, площадки ВКонтакте и Одноклассники.
11. После одобрения — «Монетизация» → включить рекламу (за награду «план» и баннер «внизу»); проверить настоящую рекламу.
12. `STATUS.md`, карточка на доске, лента; commit + push в `main`.

## ⛔ Только Роман
- Создать **сообщество ВК** и **группу ОК** для поддержки (названия без имени Роман — как у студии «Уютные игры»; сообщения включены,
  контакты скрыты) и прислать две ссылки. Без них модерация может отказать (канал поддержки обязателен).
  Готово (13 ноя): поддержка — группа студии «Уютные игры»: ВК https://vk.com/club243202759, ОК https://ok.ru/group/70000061487179 (в ОК — только ссылка ОК). Указать её же в карточках кабинетов ВК и ОК.
- Подтвердить создание приложения **SMS** (выбрать «SMS-сообщение», не пуш) и код ввести в окне на Маке.
- Если деплой идёт с Мака через терминал — подтвердить вход ВК (ссылка OAuth) один раз.
- Нажать «Опубликовать» напротив ОК (открывается окно ОК, браузер Claude его не открывает).
- Кабинет выплат: для игр — кабинет ИП (физлицо для игр не принимается с 1.04.2025); для мини-приложений — как у сонника. Анкету заполняет Роман.
- Если ВК попросит повторный вход или VPN — тоже он.

## Время поджимает
Приложение живёт до Нового года: счётчик «До Нового года» работает последние 61 день, а «План готовки» не
предлагается 31-го после 21:00 и с 1 января. Модерация ВК занимает дни — подавать заявку как можно раньше.
