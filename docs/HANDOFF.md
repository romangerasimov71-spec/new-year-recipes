## Хостинг: два варианта и рекомендация
Толик предупредил: адрес github.io в России может не открываться, и тогда модерация ВК не загрузит приложение.

**Вариант А (рекомендую): хостинг ВК.** Бесплатный статический хостинг для мини-приложений.
Приложение лежит на серверах ВК, от github.io не зависит; ВК сам проставляет адреса в «Размещении».
Ограничения (документация dev.vk.ru/ru/mini-apps/development/hosting): ZIP до 300 МБ (у нас 42 МБ), аудио и видео нельзя (их нет),
24 загрузки в сутки на приложение, хранятся 10 боевых версий. Адрес приложения меняется при каждой загрузке — ничего страшного:
сохранение в приложении идёт через хранилище ВК (VK Bridge), а не через localStorage.

Как залить (нужны Node.js и доступ к vk.ru; делает либо облачная сессия Claude Code с разрешёнными адресами `vk.ru, *.vk.ru, vk.com, *.vk.com, *.userapi.com`,
либо Терминал на Маке Романа):
1. В корне репозитория: `python3 -I tools/build-zip.py --dir build` — получится папка `build/` (только нужное, без tools/docs/release).
2. Рядом создать `vk-hosting-config.json` по образцу `release/vk/vk-hosting-config.example.json`: `static_path: "build"`, `app_id: <ID приложения>`,
   `endpoints` — `mobile`, `mvk`, `web` = `index.html`.
3. `npx @vkontakte/vk-miniapps-deploy` — утилита попросит подтвердить вход ВК по ссылке (⛔ Роман, один раз), спросит, обновлять ли адреса в «Размещении»
   (ответить «да»), и выберет боевую (production) версию. Ошибка 5 (invalid session) — удалить локальный файл `vk-miniapps-deploy.json` настроек утилиты;
   ошибка 15 — проверить `app_id`.
4. Если утилита не запускается, запасной способ: в кабинете, раздел «Размещение», загрузить ZIP — `release/vk/build.zip` (сначала `python3 -I tools/build-zip.py`)
   (этот способ не проверен вживую: если в кабинете такого поля нет — вернуться к шагам 1–3).
   Папку `build/` и `vk-hosting-config.json` в git не класть.

**Вариант Б (запасной): GitHub Pages.** В «Размещении» (мобильное приложение, веб, мобильная версия) вписать
`https://romangerasimov71-spec.github.io/new-year-recipes/`. Работает, если github.io открывается у модератора и игроков; при
блокировке — приложение просто не загрузится. Так же сделан сонник. Подходит, пока хостинг ВК не заработал.
Запускать нужно только после успеха: проверить `vk.com/app<ID>` на телефоне **без VPN**.

## Что сделать по шагам
1. **Создать приложение.** `dev.vk.ru/ru/admin/create-app` → тип «Мини-приложение» (если нет — «Игра»), название **Новогодний стол: рецепты**
   (без длинного тире). ⛔ Подтверждение — только SMS (выбрать «SMS-сообщение»), код вводит Роман на Маке. Иногда окна нет и открывается пустая
   «Доступ к приложению» — сначала проверить список приложений (не создавать второе). Записать ID.
2. **Информация.** Описание, краткое описание, слоган, Company Name — из `release/vk/texts.md`. Сообщество поддержки не указывать
   в поле «сообщество» (по навыку — пусто), ссылка на поддержку — в самом приложении.
3. **Ссылки поддержки и адреса в приложении.** Поддержка уже вписана (13 ноя, группа студии «Уютные игры»):
   - `SUPPORT.vk = "https://vk.com/club243202759"`, `SUPPORT.ok = "https://ok.ru/group/70000061487179"` (в ОК — только ссылка ОК);
   - `APP_URL.vk = "https://vk.com/app<ID>"` (ID известен сразу после создания);
   - поднять `version` до 1.0.1.
   Затем `python3 -I tools/build-zip.py` (и `--dir build` для утилиты), пересобрать, commit + push в `main`, обновить `gh-pages`:
   `git fetch origin main && git push origin origin/main:refs/heads/gh-pages`.
4. **Размещение и хостинг.** Вариант А (или Б). Состояние «Включено». Проверить `vk.com/app<ID>`: приложение грузится.
5. **Отображение.** Книжная; элементы управления — «Над окном»; адаптация под iPhone — «Отключена». Сохранить.
6. **Оформление.** Иконки: универсальная 576 (`icons/icon-576.png`, 278 и 150 подставятся), фавикон 32 (`favicon-32.png`).
   Изображения: большой сниппет `snippet-1120x630.png`; скриншоты — сначала переключить «Книжная» (600×1200), затем по одному
   (после каждого перезагрузить страницу). Порядок: `1-glavnaya`, `3-shagi`, `4-menyu`, `5-skolko-blyud`, `7-plan`, `8-otkrytka`
   (минимум 3; «Загрузить ещё» мини-приложения не сохраняют — хватает трёх). Файлы в страницу — через fetch с
   `raw.githubusercontent.com/romangerasimov71-spec/new-year-recipes/<коммит>/release/vk/...` → File → DataTransfer. Иконку каталога менять не чаще 2 раз в 2 недели.
7. **Правовые документы.** «Использовать типовые документы». Сохранить.
8. **Проверка внутри ВК** (до заявки). Открыть `vk.com/app<ID>`:
   - **Компьютер:** запуск, рецепты, меню, покупки, открытка («Сохранить» — картинка на весь экран), «Поделиться». Открыть
     инструменты разработчика → вкладка **«Сеть»** → не уходят ли запросы к `api.playgama.com` (Playgama Bridge внутри ВК
     не должен ходить на чужие адреса; если уходят — записать, приложение должно работать и без ответа).
   - **iPhone и Android** (ссылка `vk.com/app<ID>` себе в сообщения, открыть в приложении ВК): запуск без ошибок, шрифт крупный, кнопки нажимаются,
     «Назад» работает, фото листаются пальцем, шаги и «Крупнее» открываются, план по дням.
   - **Высота настоящего баннера в альбоме:** включить в «Монетизации» рекламу для теста (или после одобрения), повернуть телефон,
     посмотреть, не закрывает ли баннер кнопки внизу экрана. Запас под баннер — `BANNER_RESERVE_PX` в `js/config.js` (сейчас 90 px); если баннер выше — поднять и пересобрать.
   - Реклама за награду («План готовки») — только по кнопке, награда после просмотра; закрыли раньше — плана нет.
9. **ОК.** «Другие площадки» → ОК → «Опубликовать». ⛔ Нажимает Роман. «OK API Error» — глюк: обновить страницу; если стоит «ID профиля» — привязано.
   Из карточки взять адрес ОК, вписать `APP_URL.ok = "https://ok.ru/game/<ID ОК>"`, `version` 1.0.2, снова собрать и залить (вариант А: новая загрузка).
   В ОК проверить на iPhone: рецепт открывается, «Поделиться» без слов «ВКонтакте», ссылка поддержки — ссылка ОК, картинки не пустые.
10. **Модерация.** Красные пункты кликабельны. Когда всё зелёное — одна заявка, площадки **ВКонтакте и Одноклассники**
    (подаёт директор — входит в «выкладывай»). Красная «Регистрация в кабинете выплат» — ⛔ анкету заполняет Роман.
11. **Монетизация.** После одобрения — «Монетизация» → включить рекламу (за награду для «плана» и баннер «внизу»); проверить настоящую рекламу
    (и что баннер не показывается на первом экране первого запуска).
12. **Записать.** `game-studio/STATUS.md`, карточка `new-year-recipes` на доске, запись в ленту, commit + push в `main`.
    Цикл закончен, когда приложение открывается у игроков в ВК и ОК и ссылки записаны в `STATUS.md`.

## Не забыть
- Приложение — сезонное: до Нового года; «План готовки» не предлагается 31-го после 21:00 и с 1 января. Подавать заявку без промедления.
- В ВК/ОК нет имитации рекламы и серой полоски баннера — всё это только на `*.github.io` и `localhost`.
- В ОК запрещены ссылки, уводящие из ОК (и слова про ВК) — в приложении они убраны; новое не добавлять.
- `build.zip` и `build/` в git не коммитятся (42 МБ, в `.gitignore`) — собираются перед загрузкой
  (иначе репозиторий быстро раздуется); для деплоя нужна свежая папка `build/`.
