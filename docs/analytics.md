# Отметки для статистики («Новогодний стол: рецепты»)

Зачем: видеть, какие рецепты открывают, собирают ли меню, доходят ли до покупок и плана по дням, делятся ли,
смотрят ли рекламу за план и где уходят. Сделано по гайду Playgama (`get_game_telemetry_guide`, версия 1.1.2)
и странице Bridge `api/analytics`. Это мини-приложение: вместо «уровней» — экраны и действия.

## Как устроено
- `js/analytics.js` (`window.Analytics`) — общий модуль студии (копия из сонника), про рецепты ничего не знает.
  Отправляет только через уже запущенный Playgama Bridge: `bridge.analytics.send(имя, данные)`. Без Bridge молчит.
- Что и когда отмечать, решает `js/app.js` (поиск по `AN.event`).
- Имена событий постоянные; всё меняющееся — в данных. Строки в данных — из коротких списков ниже
  (обрезаются до 40 знаков). Никаких личных данных, адресов, текстов, параметров запуска ВК, своих `session_id`.
- Версия приложения — `version` в `js/config.js` (сейчас `1.0.0`), уходит в `performance_sample` как `game_version`.
  Менять при каждой новой сборке на площадки.
- Переходы «назад/вперёд» браузера и площадки не отмечаются (только нажатия в приложении и первый экран).

## Что Bridge шлёт сам (мы это НЕ дублируем)
Запуск и конец сессии, время в приложении, показы рекламы (за награду и баннер), `game_ready`.
`ad_reward_failed` — не повтор: Bridge не знает, что мы перестали ждать рекламу (`timeout`) или что человек нажал «Отмена».

## События

| Событие | Когда | Данные |
|---|---|---|
| `app_opened` | приложение открылось (после чтения сохранённого) | `entry` — первый экран: `home` / `recipe` / `cat` / `menu` / `shop` / `plan` / `about`; `returning` — был здесь раньше (`true`/`false`); `visit` — какой это заход (1…10, больше — 10) |
| `first_input` | первое касание, клик или клавиша за запуск (шлёт модуль) | `input`: `touch` / `mouse` / `keyboard`; `seconds` — от начала загрузки страницы; `seconds_since_ready` — от готовности |
| `recipe_opened` | открыт рецепт | `recipe_id` (латинский id, 40 штук); `cat` — раздел рецепта (`salads`, `hot`, `snacks`, `sweets`, `trendy`); `base_cat` — базовый раздел (у модных — `salads`…, у напитков `drinks`); `source`: `cat` (список раздела), `day` («Блюдо дня» на главной), `menu` (из меню), `plan` (из плана), `link` (открыли приложение сразу на рецепте), `recipe`, `shop`, `about`, `other` |
| `menu_added` | «Добавить в меню» | `recipe_id`, `cat`, `base_cat`, `dishes` — сколько блюд в меню стало |
| `menu_ready_used` | «Готовое меню» (5 блюд одним нажатием) | `dishes` |
| `shop_opened` | открыт список покупок | `dishes` — блюд в меню, `guests` — гостей (1…40) |
| `share_clicked` | нажато «поделиться» | `channel`: `system` (системное окно телефона), `copy` (скопировали текст), `vk` / `ok` (окно «поделиться» площадки), `postcard` (открыли открытку с меню); `what`: `recipe` / `menu` / `shop` / `plan`; `recipe_id` — только при `what = recipe` |
| `postcard_saved` | открытку сохранили | `method`: `download` (файл), `fullscreen` (во ВК/ОК — картинка на весь экран, сохранить вручную), `share_file` (отправили файлом через системное меню) |
| `plan_offer_shown` | показано предложение «Составить план по дням» за рекламу (раз за запуск) | `source`: `menu` (карточка в меню), `link` (открыли по адресу `#plan`), `plan` |
| `plan_opened` | открыт экран плана, план доступен | `source`: `menu` / `link` / `plan`; `dishes` |
| `plan_unlocked` | реклама досмотрена, план открыт для этого меню | `source`: `menu` / `plan`; `late` — `true`, если реклама началась уже после того, как мы перестали её ждать, но её досмотрели |
| `ad_reward_failed` | награды нет | `reason`: `closed` (закрыта раньше конца или «Отмена»/«Назад», пока ждали), `error` (площадка сказала «ошибка» / рекламы нет), `timeout` (площадка не открыла рекламу за 12 с); `late` — опоздавшая реклама закрыта раньше конца |
| `gallery_swiped` | пролистал фото блюда (раз на рецепт за запуск) | `recipe_id` |
| `photo_opened` | открыл фото крупно | `kind`: `step` (фото шага) / `gallery` (кадр листания); `recipe_id`; `n` — номер шага или кадра |
| `fav_offer_shown` | показано предложение «В избранное» (только ВК, с 3-го захода) | `kinds`: `favorites` или `favorites_home` |
| `fav_result` | ответ на предложение | `result`: `added` / `failed` / `declined`; `kind`: `favorites` / `home` |
| `performance_sample` | скорость, раз в ~30 с видимого времени (шлёт модуль) | все обязательные поля гайда (`target_fps` = 60, `window_ms`, `active_ms`, `frame_count`, `fps_avg`, `fps_p10`, `frame_time_p50/p95/p99/max_ms`, `frames_over_50/100/250/500/1000ms`, `game_version`) + `js_error_count`, `unhandled_rejection_count`, `long_task_*` (если браузер умеет) |

### Воронка, которую из этого видно
`app_opened` → `recipe_opened` → `menu_added` (или `menu_ready_used`) → `shop_opened` → `plan_offer_shown` →
`plan_unlocked` / `ad_reward_failed` → `share_clicked`. Возврат — `app_opened.returning` и `visit`.

### Как меряется скорость
Игрового процесса нет, поэтому кадры считаются только пока человек что-то делает (касается, листает, жмёт клавиши)
и ещё 3 секунды после, и только пока вкладка видна. Раз в 30 секунд видимого времени уходит один образец,
если набралось хотя бы 20 кадров; иначе окно начинается заново.

## Как проверить
`tools/check-platform.js`, раздел «Отметки для статистики»: события и данные, только события из этого списка,
нет адресов, почты и параметров запуска. Все отметки последнего запуска видны в консоли браузера: `Analytics._log`.
